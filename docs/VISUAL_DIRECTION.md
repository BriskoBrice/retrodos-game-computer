# Visual Direction — RetroDOS Game Computer

## Core idea

RetroDOS Game Computer should feel like a fictional vintage PC that somehow survived into the modern web.

The interface is not a literal DOS clone. It combines:

- beige 1980s / 1990s PC hardware
- CRT glass, scanlines and phosphor glow
- DOS terminal language and prompts
- clean contemporary spacing and responsive interaction

The product should feel nostalgic and tactile without becoming difficult to read or use.

## Product identity

**Public name:** RetroDOS Game Computer  
**Interface short name:** RetroDOS  
**Machine name:** RD-8088

Suggested lockup:

```text
RetroDOS
GAME COMPUTER

RD-8088
```

## Primary palette

### CRT green

Primary visual mode.

- near-black / charcoal background
- deep green-black panels
- phosphor green primary accent
- muted gray-green secondary text
- warm beige / amber details inspired by old PC plastics

### Future variants

- Amber phosphor
- Cool blue phosphor

Alternative themes should change the phosphor accent without redesigning the entire interface.

## Typography

Use monospace / terminal-inspired typography for:

- headings
- navigation paths
- metadata
- system status
- buttons where appropriate

Use a highly readable companion face for longer descriptions when needed.

Retro styling should never reduce legibility.

## Interface language

DOS paths are part of the identity:

```text
C:\GAMES>
C:\COLLECTIONS>
C:\FAVORITES>
C:\HISTORY>
C:\DISCOVER>
C:\RANDOM.EXE>
```

They should behave like normal clickable/touch-friendly navigation rather than requiring users to type commands.

## Hero / home screen

The homepage should make the RD-8088 recognizable immediately.

Preferred direction:

- illustrated or rendered beige PC / CRT
- `C:\> _` displayed on the monitor
- strong headline for the DOS library
- compact catalog statistics
- search available very quickly
- recent games and collections visible without excessive scrolling

## Panels and cards

Panels should subtly evoke CRT bezels:

- rounded but not overly soft
- fine borders
- restrained inner glow
- very light scanline/noise texture
- clear hierarchy

Game cards should prioritize artwork and title rather than excessive decoration.

## Game player

The player page should feel like inserting a game into the RD-8088 rather than opening an unrelated iframe.

Include:

- title and metadata
- back / favorite / fullscreen actions
- large CRT-framed player area
- small system status line
- short game information
- control hints
- related games

## Motion

Animation should be subtle:

- short boot sequence
- phosphor cursor blink
- tiny CRT flicker / glow variation
- smooth modern transitions between library and player

Avoid aggressive glitch effects, constant distortion or fake VHS noise.

## Design rule

> Retro in soul, modern in usability.

If an effect looks authentic but makes the interface harder to use, simplify the effect.
