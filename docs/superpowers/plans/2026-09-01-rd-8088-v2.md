# RD-8088 V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first polished RetroDOS Game Computer web interface around the fictional RD-8088, with a responsive DOS/CRT library, local favorites/history, game details, and in-page Internet Archive playback.

**Architecture:** Keep the runtime framework-free and build-step-free. `index.html` provides semantic structure, `assets/css/retrodos.css` owns the complete visual system, `assets/js/catalog.js` exposes catalog data, `assets/js/core.js` contains pure reusable logic that can be tested with Node, and `assets/js/app.js` owns browser state, rendering, localStorage, navigation, and iframe playback. Classic scripts are used instead of ES modules so the project remains easy to test locally and deploy as static files.

**Tech Stack:** HTML5, CSS3, vanilla JavaScript, Node.js built-in test runner for pure logic tests, Internet Archive iframe embeds.

**Spec:** `docs/VISUAL_DIRECTION.md`

## Global Constraints

- Public identity: **RetroDOS Game Computer**; short interface name: **RetroDOS**; fictional machine: **RD-8088**.
- Primary theme is CRT phosphor green on near-black with warm beige/amber hardware accents.
- Retro effects must never reduce readability or touch usability.
- Mobile, tablet and desktop layouts are required.
- DOS path labels are visual navigation, not typed commands.
- Game files are not committed to the repository.
- Playable titles use in-page Internet Archive embeds when available.
- No frontend framework and no required production build step.
- `main` stays stable; implementation happens on `dev` until reviewed.

- [ ] **Step 3: Implement the minimum core helpers**

```js
(function (root, factory) {
  const api = factory();
  if (typeof module === 'object' && module.exports) module.exports = api;
  if (root) root.RetroDOSCore = api;
})(typeof globalThis !== 'undefined' ? globalThis : this, function () {
  function normalizeText(value) {
    return String(value ?? '').normalize('NFD').replace(/[\u0300-\u036f]/g, '').toLowerCase();
  }

  function filterGames(games, filters = {}) {
    const query = normalizeText(filters.query || '');
    return games.filter((game) => {
      const haystack = normalizeText([game.title, game.genre, game.developer, game.publisher, game.description, ...(game.collections || [])].join(' '));
      const queryMatch = !query || haystack.includes(query);
      const genreMatch = !filters.genre || filters.genre === 'all' || game.genre === filters.genre;
      const yearMatch = !filters.year || filters.year === 'all' || String(game.year) === String(filters.year);
      return queryMatch && genreMatch && yearMatch;
    });
  }

  function buildArchiveEmbedUrl(game) {
    return game?.archiveId ? `https://archive.org/embed/${encodeURIComponent(game.archiveId)}` : '';
  }

  function buildArchiveImageUrl(game) {
    return game?.image || (game?.archiveId ? `https://archive.org/services/img/${encodeURIComponent(game.archiveId)}` : '');
  }

  function uniqueSorted(values) {
    return [...new Set(values.filter(Boolean))].sort((a, b) => String(a).localeCompare(String(b), 'fr', { numeric: true }));
  }

  return { normalizeText, filterGames, buildArchiveEmbedUrl, buildArchiveImageUrl, uniqueSorted };
});
```
